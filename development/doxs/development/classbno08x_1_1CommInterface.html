Detailed Description

template<typename Derived>
class bno08x::CommInterface< Derived >

CRTP-based template interface for BNO085 communication.

This template class provides a hardware-agnostic interface for BNO085 communication using the CRTP pattern. Platform-specific implementations should inherit from this template with themselves as the template parameter.
