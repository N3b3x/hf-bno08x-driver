33/* Note on quaternion naming conventions:
34 * Quaternions are values with four real components that are usually
35 * interpreted as coefficients in the complex quantity, Q.
36 *
37 * As in, Q = W + Xi + Yj + Zk
38 *
39 * Where i, j and k represent the three imaginary dimensions.
40 *
41 * So W represents the Real components and X, Y and Z the Imaginary ones.
42 *
43 * In the Hillcrest datasheets and in this code, however, the four components
44 * are named real, i, j and k, to make it explicit which is which. If you
45 * need to translate these names into the "wxyz" or "xyzw" convention, then, the
46 * appropriate mapping is this:
47 * w = real
48 * x = i
49 * y = j
50 * z = k
51 */
