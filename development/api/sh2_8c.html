Detailed Description

API Definition for SH-2 Sensor Hub.

Author
David Wheeler
Date
22 Sept 2015

The sh2 API provides functions for opening a session with the sensor hub and performing all supported operations with it. This includes enabling sensors and reading events as well as other housekeeping functions.
