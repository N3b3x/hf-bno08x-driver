Detailed Description

Convenience C++ wrapper around the C RVC API.

The C API uses RvcHalC_t function pointers internally. The CRTP-based RvcHalInterface bridge is handled at the BNO085 class level, which creates a RvcHalC_t adapter from the user's CRTP-derived HAL type.
